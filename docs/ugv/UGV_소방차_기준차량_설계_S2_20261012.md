# 소방차 기준 차량 자료·설계 (후속 계획 S2, 2026-10-12)

이름은 계속 **"일반화한 2축 펌프차 시뮬레이션 모델"** 로 둔다. 인제·기린에 실제 배치된 차량의 제원을 확보하지 못했으므로, 아래 참고값은 비교 기준이며 실제 배치 차량 제원이라고 표시하지 않는다.
50 km/h 상한은 시뮬레이션 운영 정책이며 실제 소방차 최고속도가 아니다. 살수·진화는 범위 밖.

## 3. 판단

- 현재 모델은 질량(9.8 t)이 참고 차량총중량(12.2 t)보다 약 20 % 가볍고, 축간거리(3.8 m)는 국내 5톤급 섀시 장축(4.3 m)보다 짧으며, 바퀴(0.5 m)가 크고 네 바퀴 모두 구동한다.
  profiles 의 10 t 와 SDF 9.82 t 도 서로 다르다.
- 이 차이는 회전반경(5.4 → 6.1 m)·교차로 통과·제동·경사 결과를 바꾼다. 그래서 **현재 chain_ft 12회(현재 모델·susp_a)는 기준선(참고)** 으로 두고, 위 제안값으로 **fire_v2 후보**를 따로 만들어 S3 를 다시 한다 (후속 계획 6절 "공식 자료 반영으로 후보가 바뀌면 과거 결과는 참고로만").
- fire_v2 는 SDF·airframe(RA_WHEEL_BASE)·profiles(축간·길이·폭·질량·뒤축 위치) 를 함께 바꿔야 일관된다. 정식 모델은 바꾸지 않고 후보 폴더와 시험용 airframe·profile 로 만든다 (S5 에서 자동 대조).
- 가정값(축간 4.3, 축하중 35/65, 무게중심 1.2, 윤거)은 실제 특장 섀시 문서를 받으면 교체한다. 무게중심 높이 1.0~1.4 m 범위는 결과를 보기 전에 고정한 민감도 범위다.
- 탱크 물은 고정 질량으로 표현하고 부분 충전 출렁임은 미구현이다. 바퀴별 수직 스프링은 판스프링·강체 차축·복륜을 재현하지 않으며 롤 강성이 실차와 다를 수 있다.
