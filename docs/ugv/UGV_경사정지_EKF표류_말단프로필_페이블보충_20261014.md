### 3.2 해석 [검증-계산]
- **초기 음값 −0.44~−0.49** = 제동 중 과소 읽기(출력 −0.6~−0.8)가 충격 구간에서 일부 줄어든 잔여(출력 예측기가 앞서 있어 실제 정지 순간 음수를 지나침). 넘침 없는 회차도 −0.26~−0.32 가 있다 — 이것은 끝 램프 중 작은 과소 읽기 + 출력 예측기 선행이며 GNSS 보정으로 **단조 감쇠**(τ ≈ 1.8~2.2 s; 초반 3 s 가 느린 것은 속도 공분산이 작아 이득이 낮기 때문 [가설]).
- **양 넘침** = 1차 보정 위에 **상수 강제항**(피치 누출 a_leak)이 얹힌 응답: dv/dt ≈ a_leak − v/τ → v → a_leak·τ. a_leak 0.17~0.26 → 평형 0.30~0.47 ↔ 관측 0.28~0.43 ✓. 영점 통과(1.55~1.75 s)는 초기 음값의 지수 감쇠와 강제항 적분이 같아지는 시각 ≈ τ·ln(1 + |v0|/(a_leak·τ)) = 1.8·ln(1+0.49/0.38) = 1.5 s ✓.
- **2차 성분**: Δpitch 자체가 영점 통과 직후(≈ 2 s)까지 더 틀어지고(c: −1.25 → −1.55) 그 뒤 되돌아온다(4.4 s −1.01) — 혁신 부호가 바뀐 뒤 자세 보정 방향이 뒤집히기 때문. 속도 꼭대기(3.2~3.75 s)는 자세 회복 ≈ 1.5 s 뒤. 결합계의 ¼ 주기 ≈ 1.6~2 s → **주기 6~8 s [가설]**, 관측 창(disarm 4.5 s 뒤 EKF 동결)에 두 번째 영점 통과 없음 → 감쇠비 추정 불가, '강한 감쇠'만 말할 수 있다.
- 가속도 bias x: +0.01 → −0.05 (c), −0.04 (b, s3113 b). 음의 bias 추정 = 누출의 일부(0.05 m/s²)를 bias 로 흡수. ABL_LIM 0.4 와 멀고 TAU 0.5 라 느림 — 2차 응답의 주역이 아니다 (기여 ≤ 20 %).
- **E4 가 다른 이유**: 제동 구간 초과 0 → 자세 틀어짐 0 → 강제항 0 → 1차 감쇠만. "경계 진입 0.9 m/s 라서" 가 아니다 — E4 의 진입은 1.72(truth) 로 s0547 a(1.61)와 비슷했고, s0547 a 는 2.1 진입 회차와 같은 항목 속도였다.

## 5. ④ B 가 넘침을 줄일 근거가 있는가 — 없다; 더 직접적인 축
- 넘침 크기 = g·sin(Δpitch)·τ, Δpitch 는 제동 2.5 s 의 IMU 초과 × 혁신 지속 시간으로 쌓인다(2.2절). 끝 진입 속도(충격)는 Δpitch 를 −0.2° 더 움직일 뿐(충격 구간 Δpitch 변화 −0.19~−0.23, 그러나 a·E4 처럼 초과 없는 회차에서는 +0.05~+0.13). 따라서 **B(진입 속도 ↓)는 기대 효과 ≤ 10 %**, 반면 end_v 로 마지막 구간을 길게 저속 순항하면 혁신 적분이 길어져 Δpitch 가 커질 수 있다 [가설].
- 직접 축 (이번 진단 밖, 기록용):
  1. EKF2 GNSS 속도 가중 — 관측 분산 0.16(수신 s_variance 0.4 가 파라미터 0.3 보다 커 그 값이 쓰인 듯 [가설])·P 작음 → 혁신이 2.5 s 지속. EKF2_GPS_V_NOISE 축소 또는 시뮬 GPS s_variance 조정이면 속도가 빨리 맞고 자세로 새는 몫이 준다. 단 PX4 파라미터 변경.
  2. 시뮬 IMU 채터 편향 원인(2.3절) — gz IMU/접촉/서스펜션. 평지 제동 회차와 OFF 경사 회차에 같은 적분을 걸어 '경사 × 제동' 조건인지 먼저 가른다.
  3. 서버 정차 판정: 위치 변화(GNSS 위치 혁신 0.03~0.05 m, truth 이동 0)·GNSS 속도(0.04~0.06)는 정확하므로 park 저속 창의 입력을 EKF 속도 단독에서 벗어나게 — 정책 변경.
  4. RO_DECEL_LIM/RO_JERK_LIM — 램프 모양(0.625/s)과 충격만 바꿈; 제동 구간 길이가 길어지면 (1) 과 반대 방향.
