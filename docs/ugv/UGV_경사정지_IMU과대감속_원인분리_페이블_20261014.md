### 2.2 패턴·위상 (`imu_phase_out.txt`) [검증]
- IMU 표본 시각은 모두 4 ms 격자(%4000 µs = 0) — 물리 2 ms 스텝의 격 스텝.
- 임펄스(x < −2.5) 표본의 20 ms 위상 분포: d6 A 슬롯 0·4 ms 에 120/123·120/123, 8·12·16 ms 에 0~6; b·c 는 4·8 ms; s3113 b 는 12·16 ms (89~90/122); **a 는 0·4·12·16 ms 에 각 ~60/123 (교대)**, 8 ms 는 0. E4b s1096 a 는 모든 슬롯 25~32/123 (고른 분포, 임펄스 아님). OFF s0547: 0·8·12·16 ms 에 ~45/82, 4 ms 1/83 (100 Hz 패턴).
