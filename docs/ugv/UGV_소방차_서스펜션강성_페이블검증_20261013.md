## 요약

1. **Δfn/Δq 추정기는 옳다. 불일치는 물리 엔진(DART) 시간 적분 방식에서 생긴다.** 평탄 정지에서 바퀴마다 `k·(q − ref)` 를 계산하면 앞 40,892 N·뒤 111,003 N 인데, 실제 하중(fn − 비스프렁 중량)은 20,198 N·37,676 N 이다 (비 0.494 / 0.339). 대각 판의 Δfn/Δq (354 / 458 kN/m) 와 같은 비율이다. 즉 관절이 전달하는 힘이 설정 스프링 힘보다 작다. **[검증]**
2. 원인: DART 는 관절 스프링·댐퍼를 순동역학(접촉 전) 단계에서 **반암시적**으로 계산한다(`springForce = −k·(q − ref + q̇·Δt)`, 관절 투영 관성에 `Δt·d + Δt²·k` 추가). 그런데 접촉 임펄스 단계는 **비암시적** 관성(`getInvProjArtInertia()`)을 쓴다. 접촉으로 받쳐진 바퀴는 순동역학 단계에서 매 스텝 `−g·(M+m)/m` 로 "자유낙하" 예측되고, 그 예측 속도에 댐퍼·스프링이 반응한 힘이 차체에 전달된다. 정상상태 결과:
   **`k·(q − ref) = F_load · [1 + (d + k·Δt)·Δt·(1/m_u + 1/M)]`** (m_u 비스프렁 질량, M 바퀴당 스프렁 질량). 이 식이 소방차 fire_v2·소방차 susp_a·UGV susp_a 의 평탄·판 시험 48 개 바퀴-조건을 모두 1 % 안에서 재현한다 (UGV 비 0.64 도 1/1.560 = 0.641 로 정확히 나온다). **[검증 — 소스 + 데이터]**

### 1.2 메커니즘 (DART 소스) **[검증]**

- gz-physics dartsim `SDFFeatures.cc` `CopyStandardJointAxisProperties`: `mDampingCoefficients = Damping()`, `mRestPositions = SpringReference()`, `mSpringStiffnesses = SpringStiffness()`, 위치 한계·effort(힘 한계) 그대로 복사, `mIsPositionLimitEnforced = true`. 액추에이터 타입 설정 없음(PASSIVE/FORCE 기본). → SDF 값은 그대로 DART 에 들어간다.
- DART `GenericJoint::updateTotalForceDynamic`: `springForce = −k ⊙ (q − q_rest + q̇·Δt)`, `dampingForce = −d ⊙ q̇`.
- `updateInvProjArtInertiaImplicitDynamic`: `projAI = Jᵀ·A·J + diag(Δt·d + Δt²·k)`; `updateAccelerationDynamic` 은 이 **암시적** 관성을 쓴다.
- `addChildBiasImpulseToDynamic`, `updateVelocityChangeDynamic` (접촉 임펄스 전파)은 **비암시적** `getInvProjArtInertia()` 를 쓴다.

결과(2 물체 1 차원 유도): 순동역학 단계에서 접촉이 없는 것으로 가정하므로 바퀴 하위 트리(m_u)는 차체 하중을 짊어진 채 `a_c = −g − F/m_u` 로 가속하고 차체는 `a_b = −g + F/M`. 관절 예측 속도 변화 `Δ = Δt·(a_c − a_b) = −Δt·F·μ`, `μ = 1/m_u + 1/M`. 전달력 `F = s + (d + k·Δt)·Δ` → **`F = s / (1 + (d + k·Δt)·Δt·μ)`**, `s = k·(q − ref)`. 접촉 임펄스는 바퀴 속도만 0 으로 만들고(수직 prismatic 축은 비암시적 경로에서 차체와 결합되지 않음) 차체에는 F 만 남는다. 정상상태 `F = M·g` 이므로 `k·(q−ref) = M·g·(1 + (d + k·Δt)·Δt·μ)`.
속도 항까지 같은 인수로 나뉘므로 접촉 중에는 **k_eff = k/fac, d_eff = d/fac** 로 거동한다 (fac = 1 + (d + k·Δt)·Δt·μ). 바퀴가 떠 있을 때(접촉 임펄스 없음)는 반암시적 적분이 자기일관적이어서 설정 k·d 가 온전히 작용한다 — 접촉 유무에 따라 강성이 바뀌는 비물리적 특성. **[추정 — 유도]**

## 2. Q2 — "직렬 ≈700 kN/m" 의 의미

- 접촉 유연성이 아니다 **[검증]**: 바퀴 중심 높이(dynamic_pose) = 0.4200 (평탄), 0.4400 / 0.4700 (2 / 5 cm 판) → 침투 0.0 ± 0.1 mm. DART 접촉은 속도 수준 제약(ERP/CFM 기본값)으로 사실상 강체 접촉이고, 월드·모델에 kp/kd/soft_cfm 설정도 없다. 700 kN/m 였다면 뒤축 38.5 kN 에서 55 mm 침투가 보여야 한다.

## 5. 권고

뒤축 `spring_stiffness` 한 항목만 바꾸는 사전등록 계획은 유효하되, 설정값은 "유효 강성 = 설정 × 비율" 이 아니라 `k_eff = k / [1 + (d + k·Δt)·Δt·(1/m_u + 1/M)]` 로 구해야 한다 — 이 식은 DART 가 접촉 전 순동역학에서 스프링·댐퍼를 반암시적으로, 접촉 임펄스는 비암시적으로 처리해서 생기는 적분 인공물을 정확히 기술하며 세 모델·48 개 바퀴-조건을 1 % 안에서 재현한다. 뒤축 유효 857 kN/m 목표에는 **k_rear = 2,573,000 N/m** (사전등록 선형식의 2,505,500 도 유효 835 kN/m 로 수용 가능하지만 어느 식을 쓸지 결과 전에 확정), 예상 정지 뒤축 q 0.015 m, 0.08 m 까지 여유 0.065 m, f 2.38 Hz 를 함께 기록해 두고 평탄·뒤판 2 cm 로 바로 확인하라. 두 가지를 결과 전에 명시해야 한다: (1) 유효 감쇠도 같은 인수로 줄어 ζ_eff 가 0.34 → 0.24 로 떨어지므로(요철 울림이 길어짐) "수렴 10 %" 불합격 시 다음 후보는 감쇠 d 조정이 된다는 것, (2) 5 cm 뒤판의 "최소 하중 ≥ 0.5" 항목은 강성 증가의 직접 결과로 0.44 가 예상되어 불합격이 나올 것이므로 그 항목의 의미(강성 목표와 상충)를 지금 재정의하거나 목표를 ≤ 771 kN/m 로 낮추는 선택을 먼저 하라. 더 근본적인 해법(Δt 축소, 비스프렁 질량 증가로 인공물 자체를 줄이기)은 모든 차종의 측정값을 바꾸므로 이번 단일 변경 범위에 넣지 말고 별도 과제로 남긴다.
