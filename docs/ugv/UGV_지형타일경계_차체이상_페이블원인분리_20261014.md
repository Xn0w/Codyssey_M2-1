엔진 충돌 범위 해석: ODE 유한(non-wrap) 높이장은 `dGeomHeightfieldDataBuild` 에 준 폭 안에만 존재하고 AABB 반폭 = 폭/2 이므로, 폭 = 999.023 m. 1000 m 간격으로 놓인 타일 사이에 **0.977 m 띠** 가 생긴다: x=4380 이음매는 (4379.512, 4380.488), 모든 y 이음매도 같다. z 최저 −0.05 는 ODE 두께(thickness) 0.05 로 보인다 (DART OdeHeightmap 기본, 기억 기반).

어떻게 999.02 가 나오는가 (가설, 소스 미설치): gz-physics `dartsim/src/CustomHeightmapShape.cc` 가 `vertSize = (영상 폭 × 표본화) − 1` = 1024 점을 쓰고 간격 = 1000/1024 = 0.9765625, DART `setOdeHeightfieldDetails` 가 폭 = (점수 − 1) × 간격 = 999.023 을 ODE 에 준다. 그러면 (i) 영상 마지막 행·열(1024) 이 물리에 들어가지 않고, (ii) 점 k 가 x_local = −499.512 + k·0.9766 에 놓여 의도 위치(−500 + k·0.9766) 보다 +0.488 m 밀린다. 1025 점·간격 1000/1025 변형도 같은 반폭을 주며 로그만으로는 구분 불가 — 어느 쪽이든 띠 폭은 같다. 상류 소스로 확인할 파일: gz-physics7 `dartsim/src/CustomHeightmapShape.cc`, gz-sim8 `src/systems/physics/Physics.cc` (heightmap 분기, 표본화 인자), DART 6.13 `dart/collision/ode/detail/OdeHeightmap-impl.hpp`, ODE 0.16 `ode/src/heightfield.cpp` (`dCollideHeightfield` 의 경계 셀 클램프·삼각형 안 접촉 필터).

밀림 가설이 분석기 값에 주는 영향 (fable_seam/static_assets_check.json): 경로 300 m 를 2 m 간격으로 비교하면 엔진 격자 − 분석 격자 높이 = 평균 +0.004, 범위 −0.001..+0.025 m, 스폰 0.000. **접지 판정 임계 0.03 m 에 비해 무시할 수 없는 분석기 불확실성** (판정 변경 제안 아님, 알림).

삼각분할: ODE 는 셀마다 고정 대각선으로 삼각형 2 개를 만들고, 다른 기하와 삼각형 평면으로 충돌시킨 뒤 삼각형 수평 범위 안의 접촉만 남긴다 (기억 기반). 경계에서는 **공유 격자점 자체가 없으므로** 끝점 높이 차 7 mm/2.7 mm 는 충돌 연속성과 무관하다 — 이음매 연속성은 PNG 가 아니라 엔진 범위에서 깨진다.

생성기 docstring 의 과거 관찰 (`quantize`): "세로 크기 655 m 로 맞추면 DART 높이장 충돌이 깨져 출발 즉시 튕김 (2026-10-11)" — 엔진 높이장 경로에 설명되지 않은 민감성이 이미 한 번 있었다. 별개 미해결 항목으로 기록.
