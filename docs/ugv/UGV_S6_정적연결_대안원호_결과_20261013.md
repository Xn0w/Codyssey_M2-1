## 1. 원인 (진단)

- 첫 단절은 모두 `DriveGraph._lab_ok` (한 도로에서 진입 원호 접선 + 진출 원호 접선 ≤ 도로 길이) — 기존 단일 회전 거절 목록(blocked_turns)으로는 설명되지 않던 추가 기하 조건. 예: 683500210(34.9 m) 진입 13.16 + 진출(21°, R 140.3) 25.58 = 38.7 m; 683500938(10.9 m) 9.2 + 8.65.
