## 4. 원인 [코드·기록으로 확인]

- F1 (`vehicle._safe_stop`): 업로드 전 `v_cap = max(min(지금 속도, items[0] 계획 속도), 0.5)` 를 DO_CHANGE_SPEED 로. 이번 기록에서 items[0] 속도는 1.41~2.69 m/s 라, 9.2~9.4 m/s 에서 정지 명령 직후 PX4 순항 속도가 1.4~2.7 m/s 로 고정되고 정지 경로 남은 구간을 그 속도로 간다 (감속 램프 대신 일정 저속).
- 정지 감독 (`_sup_begin`): `t_allow = 2·reach / v0 + 지연 + 4.0 s` (처음 속도에서 선형 감속 가정) ≈ 12.3 s. 저속 순항으로 가면 남은 거리를 이 시간 안에 못 간다. 시간 초과 때 속도 < 1.2 m/s 면 '저속 마무리' 로 고장 아님(구동 차단만)이지만 s3113 은 1.43~1.74 m/s → 고장.
- s0547 은 상한이 높아(2.2~2.7) 마감 직전에 섰다. 상한이 낮을수록(경사·경로 형태에 따라 items[0] 속도가 낮을수록) 시간 초과.
- 이것은 F1 의 상한 값 선택과 정지 감독 시간 모델이 서로 맞지 않는 **설계 충돌**이다. Fable R1 은 '상한을 업로드 전에' 를 권고했고, 값으로 items[0] 계획 속도를 쓰는 것이 이번에 처음 실주행에서 드러난 문제다 (E2 1회는 s0547, 상한 2.48 — 통과).
