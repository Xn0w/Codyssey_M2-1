- F1 (`vehicle._safe_stop`): 업로드 전 `v_cap = max(min(지금 속도, items[0] 계획 속도), 0.5)` 를 DO_CHANGE_SPEED 로. 이번 기록에서 items[0] 속도는 1.41~2.69 m/s 라, 9.2~9.4 m/s 에서 정지 명령 직후 PX4 순항 속도가 1.4~2.7 m/s 로 고정되고 정지 경로 남은 구간을 그 속도로 간다 (감속 램프 대신 일정 저속).

- 끝 경계 정지가 매 회차 −5.5~−5.9 m/s² (경계 진입 ≈ 1.9~2.0 m/s → 0.4 s 안 정지). 직후 EKF 속도 0.05 → 0.3~0.57 반등, 가속도 bias x 가 −0.02~−0.05 로 이동 (EKF2_ABL_LIM 0.4, TAU 0.5).
- 정지 중 accel x = 경사 중력 성분 (s0547 −0.54 ≈ g·sin 3.2°, s3113 −0.36 ≈ 2.1°) — 자세 추정과 함께 정상이면 속도 표류가 생기지 않아야 함.
- 성공/실패는 0.3 이상 표본이 park 판단 창 어디에 떨어지느냐: b·s3113 c 는 초반 반등이 저속 타이머를 한 번 지웠지만 뒤에 2.0 s 를 채움, c 는 fin+2.0 s 후반 표류가 지워 상한. **'s0547 b 최대 0.299' 라는 앞 보고는 후반 표류만 본 값 — b 도 초반 반등 0.311 로 한 번 초기화됐다 (정정, Codex 지적).**
- OFF 회차(RA −1)는 finished 뒤 실제로 굴러가(크롤 2~6 m/s) EKF 표류 비교군이 아님.

[가설 — 미확정] 경계 진입 속도가 높아(항목화 (c) '끝 항목 = 진입 속도') PX4 끝 경계 급정지가 세지고, 그 충격 뒤 EKF 가 가속도 bias·자세를 잘못 학습해 경사 위 정지에서 속도가 표류. E4 도착(경계 진입 ≈ 0.9 m/s)은 반등·표류가 더 작다. 확인에는 같은 조건에서 경계 진입 속도만 다른 비교나 EKF 혁신·자세(q) 시계열의 추가 분석이 필요.
- 서버가 실제 받은 속도 표본 시계열은 기록이 없다 (park_events 는 판단·초기화 순간만). 다음 회차엔 park 감시 표본(시각·값·나이)을 짧게 남기는 계측이 필요.
- 문턱·상한·감독 마감·EKF 값 강제는 바꾸지 않는다 (Codex 0430).
