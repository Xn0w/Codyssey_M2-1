## 0. 요약

1. **힘 부호·프레임·점 대응 (확인):** 1,293 점 전부 법선 z > 0, 바퀴 쪽 힘 F·n ≥ 0 → DART 정의(normal = body2→body1) 로 **모든 점에서 엔진 body1 = 바퀴**. body_1 힘을 메시지 안에서 합한 값 = 그 바퀴에 작용하는 순힘이 맞고, 네 바퀴 합은 정지 표본에서 ΣFz = 15,915.2 N·ΣFx = 0.000 N (월드 프레임). 기존 분석기의 "FR 한 점은 body1 ≠ 바퀴" 는 **힘이 0 인 점 (45.144 s, f = 0) 에 +z 추론을 적용한 산물** — 순서 불일치 아님.
2. **마찰 모델 (소스 확인):** DART ContactConstraint = 점마다 3 행 (법선 λ0 ≥ 0, 1차 |λ1| ≤ μ1·λ0, 2차 |λ2| ≤ μ2·λ0 — findex 상자, 원뿔 아님), 힘 = n·λ0/Δt + D0·λ1/Δt + D1·λ2/Δt, D = `getTangentBasisMatrixODE(n)` (D1 = n × 첫 마찰방향, D0 = D1 을 n 둘레로 90°). ERP 0.01·최대 오차복원속도 **1e-3 m/s**·CFM 1e-5 가 기본값이며 월드/모델에 재설정 없음. 자료 대조 결과 **첫 마찰방향 = 바퀴 fdir1 (차량 전방)** 기저에서 FL·RL·RR 모든 점이 |λ|/fn ≤ 1.0017 (FL 최대 1.0001 = 정확히 한계) 이고 DART 기본 UnitZ 기저에서는 FL 4 점이 1.15 로 위반 → 적용 기저 = fdir1. μ1 = μ2 = 1.0 (바퀴·타일 SDF).
3. **점별 1.71 의 의미 (확인 + 미확인 1):** 두 점을 가진 FR 에서만 점별 비가 1.21~1.71 (상자 √2 초과). 그러나 **같은 메시지 두 점의 합** 은 축방향 |λ|/Σfn 최대 1.0027, 전 표본 위반 0 → 한계는 바퀴(두 점 합) 수준에서 정확히 μ = 1 로 지켜진다. 점별 비는 2 점 바퀴에서 마찰 한계 지표로 쓸 수 없다. 두 점 사이의 임펄스 배분이 점별 상자를 넘는 이유는 소스로 닫지 못함 (미확인; 물리 버그로 확정하지 않음).
4. **실제 현상 (원본에서 확인, 결정론적 — b4_R1y 와 b4e_exact 의 FR 메시지 수 14,966 동일):** FR 접촉 깊이가 **정확히 −0.999 mm/s** (= DART 최대 오차복원속도) 로 회복하다가 **4.43 s 마다** 5.5 mm → 9.9 mm 로 점프하는 톱니. 점프 직전 FR 접촉점의 경계선 거리 dy = 0.000~0.004 mm (선 위), 직후 0.17~0.30 mm. 점프 때 FR 접촉 메시지 4~6 스텝 누락 (c_age 0.010~0.012 s, 30 s 에 36 스텝), ΣFz +200 N·ΣFx 최대 4,850 N 과도, FL/FR 축력 부호 반전 → 2.9 kN 선형 복귀. 사이클 사이 FL −3.96 kN / FR +3.62 kN 의 **상쇄되는 축방향(월드 x) 마찰 쌍** 이 유지되고 (순힘 0, 차축 인장), FR 바퀴는 +1.0 mm/s 로 상승, q_FR +0.50 / q_FL −0.50 mm/s, 차체 원점은 0.1 mm 안에서 정지, 피치가 0.93 mrad 범위에서 오르내림 → 접촉점 y 드리프트 −0.063 mm/s 는 **자세 변화의 기하 효과** (0.35 m × 피치율), 미끄러짐 아님. N/S 대조는 모든 양이 1e-4 mm 수준으로 상수, 깊이 0.0005 mm, 비 ≤ 0.02.
5. **원인 가설 (강, 소스·자산·자료 일치):** ODE 높이장은 타일별로 "그 타일 삼각형 평면에 대한 원통 최저점" 을 만들고 그 점이 자기 삼각형 수평 범위 안일 때만 접촉으로 남긴다 (`IsOnHeightfield2`, 상한 배타). 두 타일의 경계행 평면 기울기가 다르면 (T16_06 dz/dy −0.00300, T16_05 −0.00245 — 양자화 간격이 달라 1 mm/0.98 m 단차) 원통 최저점은 축에서 각각 −1.05 / −0.86 mm 어긋나 **축 y 가 (−4630.99914, −4630.99895) 인 0.19 mm 띠에서는 어느 타일도 접촉을 만들지 않는다.** FR 축은 그 띠 북쪽 0.25 mm 에 있고, 깊이 회복에 따른 피치 변화로 접촉점이 선에 닿으면 (4.4 s) 접촉 상실 → 스프링 예압 아래 자유 낙하 (30 kg, ≈118 m/s², 5 스텝 ≈ 6 mm) → 10 mm 관통 재접촉 → 과도 → 축이 0.2~0.3 mm 북으로 → 반복. 깊이 > 0 인 동안 ERP 가 FR 접촉을 기울어진 법선(x 로 0.875°) 방향으로 1 mm/s 밀어 수평 성분을 요구하고, 강체 차축·수직 서스펜션·다른 바퀴 마찰이 이를 막아 **FR 축방향 마찰이 μ 한계로 포화** (FR 마찰 +x = 법선 x 기울기 방향 ✓), FL 이 반작용 → 큰 축력. 깊이 0 이면 (N/S) 요구가 없어 축력 없음.
6. **c1 잔여 결함인가:** 아니다 — 기전 (타일별 접촉 소유·배타 경계·ERP/ERV·상자 마찰) 은 엔진 속성이고 c1 과 무관. 다만 보정 전 타일은 경계에 0.976 m 충돌 공백이 있어 이 배치는 바퀴가 빠지는 큰 결함으로 나타났을 뿐 (X 경계 1차 검토), 같은 띠 현상은 **두 충돌면이 실제로 만나는 모든 경계** 에서 생길 수 있다. 띠 폭 = R·|Δ(dz/dy)| 는 타일 간 양자화 단차에서 커지고 (여기 0.19 mm), 한 타일 안의 인접 셀 사이에도 원리상 존재하나 지형 곡률 수준 (≈ 0.01~0.04 mm) 이다.
7. **주행 중 위험 (추정):** 정적 한계 사이클은 **바퀴 축이 경계선 ±0.3 mm 안에 정지** 할 때만 성립. 통과 중에는 띠(0.19 mm) 를 1 스텝 안에 지나므로 최대 1 스텝 접촉 상실 (낙하 ≤ 0.24 mm) → 재접촉 깊이 < 0.3 mm → 1 mm/s 복원 0.3 s 동안 작은 마찰 포화 과도. 확률 ≈ 띠폭/(v·Δt) = 1 m/s 에서 ≈ 9 %, 5.56 m/s 에서 ≈ 1.7 % (바퀴·경계당). 주행 판정에 영향 줄 크기는 아니나, **경계선 위 정차** 는 4.4 s 주기 Fz +200 N·Fx 수 kN 의 차체 트위치(IMU) 와 5~12 mm 톱니 관통을 만들어 '자체 정지' 류 판정을 오염시킬 수 있다. 기준 완화 제안 없음.

## 2. 질문 1 — 힘 부호·프레임·점 대응

소스 사슬 (사본 행 번호): DART `Contact.hpp` normal = bodyNode2→bodyNode1, force = bodyNode1 에 작용 (월드) → gz-physics `SimulationFeatures.cc 262~289` `convertContact`: collision1/2 = DART collisionObject1/2, extraData {force, normal, depth} 그대로 → gz-sim `Physics.cc 4305~4420`: 같은 ContactPoint 포인터를 `entityContactMap[coll1][coll2]` 와 `[coll2][coll1]` 양쪽에 넣고, 메시지 `collision1 = 센서(요청) 엔티티`, `body_1_wrench.force = force` (= **엔진 body1 에 작용하는 힘, 메시지 collision1 과 무관**), `body_2 = −force`, normal·depth 그대로. body 이름은 채우지 않음 (`b1`,`b2` 빈 문자열 — 관측과 일치).

따라서 엔진 body1 판별은 힘 부호가 아니라 **법선 방향** 으로 해야 하고 (normal 은 body2 → body1), 바퀴가 지형 위에 있으므로 n_z > 0 ⇔ body1 = 바퀴. 결과:

| 회차 | 점 수 | n_z < 0 | F_w·n < 0 | 네 바퀴 ΣFz (정지 표본) | ΣFx |
|---|---|---|---|---|---|
| b4e_exact | 1,293 | 0 | 0 | 중앙 15,915.2 (과도 때 15,878~16,123) | 중앙 −0.001 (과도 −465~+4,850) |
| b4d_N | 1,295 | 0 | 0 | 15,915.2 (상수) | 0.000 |
| b4d_S | 1,554 | 0 | 0 | 15,915.2 (상수) | 0.000 |

→ 모든 점에서 body1 = 바퀴, body_1 힘 합 = 바퀴 순힘, 프레임 월드. 기존 `wheel_is_engine_body1: [false, true]` 는 45.144 s FR 점 (f1 = (0,0,0), d = 11.3 mm) 의 `f1.z > 0` 가 거짓이 된 것 — 힘 0 인 점에 부호 추론을 적용한 산물. 점별 큰 접선 성분과 집계 순힘은 3 절에서 분리.

## 3. 질문 2 — 실제 마찰 모델과 1.71 의 해석

### 3.1 소스 (dart_ContactConstraint.cpp)
- 44~57 행: `DART_ERP 0.01`, `DART_MAX_ERV 1e-3`, `DART_CFM 1e-5`, 오차허용 0. 월드·모델 SDF 에 재설정 없음 (gz-physics 가 바꾸지 않음).
- 371~392: 마찰 켜짐이면 3 행 — `lo[0]=0, hi[0]=∞`; `lo[1]=−μ1, hi[1]=+μ1, findex[1]=0`; `lo[2]=−μ2, hi[2]=+μ2, findex[2]=0` → **점별 상자** |λ1| ≤ μ1λ0, |λ2| ≤ μ2λ0 (원뿔 아님; 두 방향 동시 포화 시 합 √2·μ·λ0).
- 397~429: `b[0] += min(ERP·depth/Δt, MAX_ERV)` — 깊이 > 0 이면 법선 방향 상대속도 목표 (여기 depth 5~12 mm → 0.01·d/0.002 = 25~60 mm/s 가 상한 1 mm/s 로 잘림).
- 633~652: 힘 = n·λ0/Δt + D.col(0)·λ1/Δt + D.col(1)·λ2/Δt.
- 771~826: `D.col(1) = normalize(n × mFirstFrictionalDirection)`, `D.col(0) = col(1) 을 n 둘레로 +90°`. 첫 마찰방향 기본값은 헤더 상수 (사본 없음), gz-physics `SimulationFeatures.cc 371·403` 가 ContactSurfaceParams 로 전달 (fdir1 비영 때 DART DynamicsAspect 값). 바퀴 collision `<fdir1>1 0 0</fdir1>` = collision x = 차량 전방 = 월드 +y (yaw π/2).

### 3.2 자료로 기저 확인
두 후보 기저로 모든 점을 분해해 상자 위반 수를 셌다 (`raw_points_analysis.json`):

| 바퀴 (b4e_exact) | 점/메시지 | 점별 ft/fn max | UnitZ 기저 max |λ|/fn (위반 점) | **fdir 기저** max |λ|/fn (위반 점) |
|---|---|---|---|---|
| FL | 1 | 1.315 | 1.148 (4) | **1.0001 (0)** |
| FR | 2 (257), 1 (2) | **1.712** | 1.424 (239) | 1.210 (256) |
| RL | 1 | 1.417 | 1.153 (2) | 1.0017 (0) |
| RR | 1 | 1.152 | 0.968 (0) | 0.898 (0) |

- 1 점 바퀴 세 개가 fdir 기저에서 전부 ≤ 1.002 이고 FL 이 **정확히 1.000 (포화)** → 실제 기저 = fdir1 (전방/축). UnitZ 기저는 FL 에서 위반이 나와 배제.
- 점별 ft/fn 은 상자 기저와 무관하게 √2 를 넘을 수 없는데 FR 에서 1.71 → **같은 메시지 두 점의 합** 으로 다시 검사 (`cycle_and_sum_check.out`): FR 합의 축방향 |λ|/Σfn 최대 **1.0027**, 전방 1.0027, 위반 0 (N/S 의 2 점 바퀴 RL·FL 도 합 ≤ 0.02). 즉 한계는 바퀴(두 점 합) 수준에서 μ = 1 로 정확히 지켜지고, **두 점 사이 배분만 점별 상자를 넘는다** (예: 45.252 s FR 점 A fn 1,004 N 에 접선 (1,215, 1,215) N; 점 B 가 나머지).
- 결론: Codex 가 보류한 "√2 대각 한계" 표현은 **점별로는 성립하지 않고 바퀴 합으로는 μ·Σfn 한계 포화** 가 맞는 표현이다. 점별 1.71 은 물리적 마찰 한계 위반의 증거가 아니라 2 점 임펄스 배분의 보고 특성이다. 왜 점별 상자가 안 지켜지는지 (Dantzig/PGS 의 findex 처리·접촉 병합 여부) 는 사본 범위 밖 — **미확인**. 판정기가 점별 비를 쓰면 2 점 바퀴에서 거짓 위반을 만들 수 있다 (기준 변경 제안 아님, 알림).

## 5. 가설 — 경계행 접촉 소유와 ERP 마찰 포화 (강)

### 5.1 ODE 소스 (ode_heightfield.cpp)
- 1790~1803: 다른 기하의 AABB 를 표본 간격으로 나눠 셀 범위 [nMinX, nMaxX]·[nMinZ, nMaxZ] 를 0..n−1 로 클램프 → 경계행까지의 마지막 셀도 포함 (경계행 자체는 양 타일이 각자 가짐).
- 1300~1349: 셀마다 삼각형 ABC(up)·DBC(down) 생성 (`isACollide = AHeight > minO2Height` 로 후보만). 1440~1470: 같은 평면식 삼각형을 묶어 평면 목록.
- 1497~1520: 평면마다 `geomNPlaneCollider(o2, sliding_plane)` (원통은 `dCollideCylinderPlane`, 1088 행) 로 접촉 후보 생성 → 각 후보 위치가 **그 평면의 삼각형 중 하나의 수평 범위 안일 때만** 채택 (`IsOnHeightfield2`, 264~330: 하한 포함·상한 배타, 대각선 분할).
- 즉 접촉점 = "그 평면(타일·삼각형) 기준 원통 최저점" 이고, 그 점이 자기 삼각형 밖이면 버린다. 타일이 다르면 평면이 다르고 최저점도 다르다.

### 5.3 사이클 (각 단계의 근거)
1. 접촉 상실 → FR 바퀴(30 kg, 스프링 예압 ≈ 3.5 kN) 자유 낙하 ≈ 118 m/s²: 5 스텝(10 ms) ≈ 5.9 mm, 6 스텝 ≈ 8.5 mm — 관측 점프 4.3~5.6 mm·누락 4~6 스텝과 자릿수 일치.
2. 재접촉: 깊이 ≈ 10 mm, 비탄성 (반발 0) → ΣFz +200 N·ΣFx 수 kN 과도·피치 +0.93 mrad → 접촉점 dy 가 0.17~0.30 mm 로 복귀 (자세 기하).
3. 회복: ERP 가 FR 접촉을 법선 방향 1 mm/s 로 밀어냄 (관측 −0.999 mm/s). 법선이 x 로 0.875° 기울어 수평 성분 15 µm/s 를 요구하나 수직 서스펜션·강체 차축·다른 바퀴 마찰이 막음 → LCP 가 FR 축방향 마찰을 상자 한계 μ=1 로 포화 (FR 마찰 +x = 법선 기울기 방향 ✓, 합 |λ|/Σfn 1.003), FL 이 반작용 (1.000) → 3.6~4.0 kN 상쇄 쌍. 깊이 0 이면 요구 0 → 축력 0 (N/S ✓).
4. FR 상승 → 앞 차축 비틀림 (q_FR +0.5 / q_FL −0.5 mm/s) → 피치 복귀 → 접촉점 남쪽 드리프트 −0.063 mm/s → 4.4 s 뒤 dy = 0 → 1 로.

미확인: (a) ODE 원통-평면 접촉 위치 규칙(끝점·중점)과 점 수 조건 — 사본 없음; (b) 사이클 최초 진입 (스폰 낙하 뒤 어떤 경로로 FR 점이 선에 닿았는지 — 2 s 전 자료는 정착 제외); (c) 점별 임펄스 배분 (3.2).

## 7. 주행 중 위험·최소 진단·중단 조건

**위험 (추정, 자료 기반):** 통과 중 바퀴 접촉점이 띠(0.19 mm) 를 지나는 데 0.19 mm / v: 1 m/s 에서 0.19 ms (스텝 2 ms 의 1/10) → 한 스텝이 띠에 걸릴 확률 ≈ 9 %, 5.56 m/s ≈ 1.7 % (바퀴·경계당). 걸리면 1 스텝 무접촉 → 낙하 ≤ 0.24 mm → 재접촉 깊이 < 0.3 mm → ERP 1 mm/s 로 0.3 s 안 복원, 그동안 축방향 마찰 포화 과도 (크기는 fn 수준이나 상쇄 쌍, 순힘 ≈ 0). 차체 z/롤 영향 < 1 mm — 기존 접지 기준 (0.03 m) 에는 못 미친다. **정차** 가 축을 선 ±0.3 mm 안에 두면 4.4 s 주기 사이클 (Fz +200 N·Fx 수 kN 과도, 5~12 mm 톱니 관통, 피치 1 mrad 트위치) 이 유지되어 IMU 기반 '자체 정지'·정지 접지 판정을 오염시킬 수 있다. 경계가 아닌 곳의 정차와 모든 주행 판정은 영향 없음 (N/S·c1 300 m 와 일치). 기준 완화 제안 없음.

**최소 진단 (가설 분리용, Codex 승인 뒤 1 회, 연속 스윕 아님):** 같은 배치·v3 기록·NO_PX4 에서 **y 만 +0.002 m** (축을 선 북쪽 3.3 mm, 접촉점 2.25 mm) 로 60 s. 예측: 드리프트 −0.063 mm/s 로 선에 닿는 데 ≈ 36 s → 30 s 안 사건 0, 36 s 전후 첫 점프 1 회 (사이클 모델); 사건이 전혀 없으면 초기 진입(5.3 (b)) 이 필요조건, 30 s 안에 반복되면 모델 기각. 오프라인 선행: ODE 0.16.2 `collision_cylinder_plane.cpp` (접촉 위치·점 수 규칙) 과 DART `BoxedLcpConstraintSolver.cpp`/`PgsBoxedLcpSolver.cpp` (findex·점별 상자) 사본 확보 — 미확인 (a)·3.2 를 소스로 닫는다. 두 항목 모두 **지형·마찰·엔진·형상 변경 아님**.

**중단 조건:** 진단 회차에서 |롤|·|피치| > 3°, susp |q| ≥ 0.098 0.3 s, 접촉 메시지 나이 > 0.3 s, NO_MSG → 즉시 종료·보존 (기존 규칙). 예측 밖 결과 (예: 사건 주기·깊이 기울기가 1 mm/s 아님) 는 가설 기각으로 기록하고 추가 스윕 없이 보고. 동적 bR2y 는 이 원인 설명과 위험 추정을 리더가 수용한 뒤에만.
