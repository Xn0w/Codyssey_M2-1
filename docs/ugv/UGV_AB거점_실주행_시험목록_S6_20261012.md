## 2. 실행 전 정적 단계 (Gazebo 없음)

1. `python -m ugv.tools.ab_connect --tiles <최종 타일>` (wt_fix 또는 S5 통합 코드) — 1) 지도상 연결 2) 차종별 계획기 ACCEPT + 경로 모든 도로 정적 기준 안. **주의: 이 도구는 타일 폴더의 road_subset_all_included.json 을 다시 쓴다 → 진행 중 체인이 없을 때 실행.**
2. 차종(adair_ugv / adair_firetruck 최종 후보) × 방향(A→B, B→A) 4 조합 각각: 경로 도로 목록, 길이, 막는 도로(사유), 일방통행·회전 거절(기존 B→A 거절 회전 3곳 — 커밋 d613cc3 문서) 반영.
3. 경로가 지나는 타일이 최종 월드에 모두 있는지 타일별 확인. 빠진 타일은 같은 기준으로 월드 자산을 만들고, 평탄 지면으로 대체하지 않는다.
4. 소방차가 회전 불가로 막히면 '소방차 양방향 연결 미확인/불가' 로 남기고 도달 가능한 도로 위 접근 지점·잔여 거리를 보고한다.

판정 (회차마다): 출발·경로·도착 상태, 차체 전체 도로 경계(이탈 0), 속도·곡선 감속·경사 구간, 최종 정지 확인 후 10 s 이상 유지·재이동 없음, ETA 오차, 통신·기록 연속성.
실행 래퍼는 run_sc_v5 (정지 검사·증거 검사·출처) — 무효 회차는 valid_tally 로 제외하고 같은 조합으로 보충. 성공 경로는 처음부터 끝까지 궤적 지도와 로그로 남긴다.
한 방향 성공을 왕복 성공으로 세지 않는다. 기준(도로 폭·이탈 판정·도착 반경)을 완화해 통과시키지 않는다.
