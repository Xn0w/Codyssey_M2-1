  기존 실패 시험 `tests/test_uav_requests.py::test_route_cruise_clears_dem_terrain` (수정 전 코드에서도 실패, 이번 작업과 무관)
- 총괄 단절 10 분 정지·30 분 복귀는 20 분 안에 확인할 수 없어 별도 기록 (logs/ugv/stage4/comm_loss_wall_*: 정지·복귀 시작까지, 거점 도착은 미확인)
- 총괄 자동 지상 출동 기능은 없다 — UGV 지상 지원은 '운용자 요청' (불 확인 뒤 요청만, 차량·Safety 는 총괄)
- LLM: 20 분 정상 시연은 관측 계획 LLM 끔 (계획 지점이 사전 검증 경로가 아니므로). LLM 관측 계획은 건식 예행연습에서 1회 호출·fallback 없음
- 같은 월드 두 장비이지만 물리적 상호작용(근접·충돌) 시험은 하지 않았다 (UAV 순항 고도 약 140 m AGL)

## 8) 다시 실행할 명령

```
python integration/px4_live/run_integ.py preflight
python integration/px4_live/run_integ.py pretest --minutes 20      # 시연 경로 사전 시험 (총괄 없음)
python integration/px4_live/run_integ.py run --minutes 35          # 20 분 통합 (총괄 경유)
python integration/px4_live/run_integ.py stop                      # 긴급 종료 (이 도구가 띄운 것만)
python integration/px4_live/run_integ.py run --dry --llm-planner   # 건식 (Gazebo 없음, 실제 시연 아님)
```
같은 초기 상태: 실행마다 새 폴더(logs/integ/run_*)에 환경 상태(ENV_RESUME=0)·총괄 DB·UGV/UAV 상태를 새로 만든다. WSL PX4 파라미터·dataman 은 시작 때 지운다.
